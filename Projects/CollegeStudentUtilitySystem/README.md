# College Student Utility System

A Java console-based application that combines three useful college-related utilities into one menu-driven system.

## Features

### 1. Student Attendance Eligibility Checker

- Accepts total classes
- Accepts classes attended
- Calculates attendance percentage
- Checks examination eligibility
- Shows attendance shortage if the student is below the required percentage

### 2. College Grade & CGPA Calculator

- Accepts the number of subjects
- Accepts marks for each subject
- Calculates total marks
- Calculates average marks
- Assigns a grade
- Calculates CGPA

### 3. Library Fine Calculator

- Accepts overdue days
- Calculates library fine
- Displays whether a fine is pending

## Menu
