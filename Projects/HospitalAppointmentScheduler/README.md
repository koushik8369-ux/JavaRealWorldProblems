# 🏥 Hospital Appointment Scheduler

A Java console-based hospital appointment management system that allows users to book, view, search, reschedule, and cancel hospital appointments.

This project is built as part of my **Java Full Stack Development learning journey**, focusing on Java fundamentals, Object-Oriented Programming, collections, and real-world problem-solving.

---

## 🚀 Features

### 👤 Patient Management
- Patient ID
- Patient name
- Patient age
- Patient input validation

### 👨‍⚕️ Doctor Management
- Doctor ID
- Doctor name
- Doctor specialization
- Consultation fee

### 📅 Appointment Management
- Book appointments
- View all appointments
- Search appointment by ID
- Reschedule appointments
- Cancel appointments
- Automatic appointment ID generation
- Appointment status tracking

### 📊 Appointment Summary
The system displays:
- Total appointments
- Booked appointments
- Cancelled appointments
