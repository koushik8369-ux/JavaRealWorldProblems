# 🏥 Hospital Appointment Scheduler

A Java console-based hospital appointment management system that allows users to book, view, search, reschedule, and cancel hospital appointments.

This project is part of my **Java Full Stack Development learning journey**, focusing on Java fundamentals, Object-Oriented Programming, collections, validation, and real-world business logic.

---

## 🚀 Features

### 👤 Patient Management
- Patient ID
- Patient name
- Patient age
- Input validation

### 👨‍⚕️ Doctor Management
- Doctor ID
- Doctor name
- Doctor specialization
- Consultation fee
- Doctor availability checking

### 📅 Appointment Management
- Book appointments
- View all appointments
- Search by appointment ID
- Search by patient ID
- Reschedule appointments
- Cancel appointments
- Automatic appointment ID generation
- Appointment status tracking
- Appointment date and time

### ⏰ Doctor Availability
The system prevents two active appointments from being booked with the same doctor at the same date and time.

### 📊 Appointment Summary
Displays:
- Total appointments
- Booked appointments
- Cancelled appointments
